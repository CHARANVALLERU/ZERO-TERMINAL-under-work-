================================================================================
OBSIDIAN SYSTEM INTEGRATION PLAN - ZERO MENTAL MODEL ENGINE
================================================================================

This plan outlines the architecture, manual steps, configurations, and scripts 
required to convert the ZERO Quantitative engine into a "Mental Model Engine"
by coupling it directly with an Obsidian personal knowledge base.

--------------------------------------------------------------------------------
1. THE CORE VALUE PROPOSITION
--------------------------------------------------------------------------------
This integration bridges dry statistical calculations (ZERO's conformal daily
ranges) with conscious behavioral decision-making (your Obsidian mental logs).
1. Pre-Market: The system exports predicted ranges directly to your Obsidian 
   daily note.
2. During the Session: You log trading plans, stress levels, and voice inputs.
3. Post-Market: The engine reads notes, tags cognitive biases (e.g. FOMO, 
   Loss Aversion), and updates tomorrow's trading guards or models.

--------------------------------------------------------------------------------
2. SETUP & VAULT DIRECTORY STRUCTURE
--------------------------------------------------------------------------------
Create or structure your Obsidian Vault folder with these directories:

Obsidian-Vault/
├── 01_Daily_Logs/          # Daily files containing ZERO stats + self-reflections
│   └── 2026-07-14.md
├── 02_Mental_Models/       # Frameworks for decisions (e.g., Inversion.md)
├── 03_Cognitive_Biases/    # Rules on emotional boundaries (e.g., FOMO.md)
└── Templates/              # Note layouts for new journal objects
    └── daily_template.md

--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
Configure your template file (Templates/daily_template.md) as follows:

## 4. Post-Market Calibration (Mistake Logging)
* Did I deviate from my targets?

--------------------------------------------------------------------------------
4. PYTHON AUTOMATED SYNC CONNECTOR
--------------------------------------------------------------------------------
Add or trigger a script (e.g., engine/obsidian_sync.py) that hooks into ZERO's 
daily updating sequence (`engine/daily_updater.py`). 

The script performs the following:
1. Locates today's Obsidian log file in "01_Daily_Logs/YYYY-MM-DD.md".
2. Reads ZERO's pre-market prediction matrix.
3. Automatically writes or updates the frontmatter values and headers with 
   Nifty, Bank Nifty, and Sensex ranges.
4. Generates the template if no page exists.

--------------------------------------------------------------------------------
5. THE VOICE INPUT TRANSCRIPTION PIPELINE
--------------------------------------------------------------------------------
To log voice notes locally:
1. Record audio: Capture your thoughts daily using an Obsidian sound plugin, 
   a mobile voice app, or a local hotkey script using a microphone.
2. Local STT: Run a script pointing to OpenAI's Whisper (e.g. using `faster-whisper`
   Python package locally) to output high-accuracy text.
3. Parsing & Injection: The script reads the transcription, tags any linked
   concepts like [[FOMO]], and injects this text under the
   `<!-- VOICE_LOG_PLACEHOLDER -->` block in the matching Obsidian daily note.

--------------------------------------------------------------------------------
6. QUANTITATIVE MISTAKE-FEEDBACK LOOP
--------------------------------------------------------------------------------
How the engine learns from Obsidian logs:
1. Obsidian Tracker script reads `biases_flagged` and `score` parameters inside the
   Obsidian frontmatter.
2. When the engine updates daily predictions, it fetches this historical score metadata.
3. If past-week discipline scores are low, or multiple bias nodes are active,
   the calibrator (`engine/calibrator.py`) automatically scales down your predicted
   range bounds as a safety precaution.

7. ZERO ENGINE — AI INTELLIGENCE CORE (NEW)
================================================================================

The ZERO ENGINE is a full-screen AI chat panel built into the ZERO Terminal sidebar.
It is powered by Google Gemini (free tier) and is pre-trained on your ZERO Brain
knowledge base, candle pattern encyclopedia, trader psychology frameworks, and
all claude-obsidian-main skill/agent markdown files.

--------------------------------------------------------------------------------
7.1 HOW TO ACCESS ZERO ENGINE
--------------------------------------------------------------------------------
1. Open ZERO Terminal (streamlit run app.py)
2. Expand the LEFT SIDEBAR
3. Click "⚡ OPEN ZERO ENGINE" — it appears ABOVE the DATA section
4. A full-screen overlay opens showing:
   - The ZERO glowing pulsing logo (same animation as Quant Cores sync)
   - Status bar showing API status, knowledge entry count, session training count
   - Scrollable chat history
   - Input bar at bottom with SEND and CLR buttons
   - ⚙ ENGINE SETTINGS expander to update the API key

--------------------------------------------------------------------------------
7.2 WHAT ZERO ENGINE KNOWS
--------------------------------------------------------------------------------
Pre-loaded knowledge sources (automatically injected as system context):
  • db/brain/entries.json        — Your ZERO Brain trained knowledge entries
  • db/brain/candle_patterns.md  — Complete candle pattern encyclopedia
  • db/brain/human_mentality.md  — Trader psychology + 8 cognitive bias frameworks
  • claude-obsidian-main/agents/ — Wiki ingest, lint, verifier agent context
  • claude-obsidian-main/skills/ — Think, wiki, autoresearch, obsidian-markdown skills
  • obsidian_integration_plan.txt — This plan (ZERO's obsidian architecture)

--------------------------------------------------------------------------------
7.3 REAL-TIME TRAINING (TRAIN: prefix)
--------------------------------------------------------------------------------
You can teach ZERO ENGINE new rules at any time:
  > TRAIN: I never average down in a downtrend. This is rule #1.
  > TRAIN: Hammer at Nifty 24200 support = high probability reversal for me.
  > TRAIN: My max loss per day is 1% of capital. Stop all trading after.

Each TRAIN: entry is:
  1. Added to the live Gemini system prompt for the current session
  2. Persisted to db/brain/entries.json (your ZERO Brain)
  3. Available for all future queries across sessions

--------------------------------------------------------------------------------
7.4 CONFIGURATION
--------------------------------------------------------------------------------
API Key : Set in config.py → GEMINI_API_KEY
          Or via environment variable: set GEMINI_API_KEY=your_key_here
          Or update in-app via ⚙ ENGINE SETTINGS expander
Model   : gemini-1.5-flash (free tier, no billing required)
History : Persisted to db/brain/engine_chat_history.json (last 200 messages)
Source  : https://aistudio.google.com (free Gemini API key)
