# Fincept Multi-Agent Consensus Framework

Simulates a 3-agent quant desk:
1. **Quant Strategist**: Evaluates technical momentum, trend, and alpha signals.
2. **Risk Analyst**: Applies half-Kelly sizing and computes maximum drawdown risk.
3. **Microstructure Specialist**: Analyzes spreads, liquidity depth, and order book imbalance.
